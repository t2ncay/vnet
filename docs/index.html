// premise

The screen you're looking at is the whole game

There's no HUD, no third-person camera, no menu standing between you and the fiction. VEKTRAOS is a full desktop simulation — a terminal, a browser, and a handful of widgets — and everything you do happens inside that OS. You've logged into VNET, a decentralized darknet running over real UDP sockets, and you're reading pages, joining chatrooms, and slowly raising your trace level just by staying connected.

The longer you linger, the more attention you draw. Eventually, without warning, that attention turns into a raid — and the calm you'd settled into is the whole reason it lands.

// federal raid system

Fifteen seconds. Three ways out.

Raids trigger probabilistically off your own trace level — rare and almost paranoid at low trace, close to certain once you're past 70%, worse still if you're already flagged. Sit on a pile of vcoin and the raid skews economic; the game is always reading your state before it decides how to come after you.

When it triggers, the whole interface reacts: a pulsing red border, glowing corner reticles, a badge that slams into place. You get one alert window to notice, then a real-time minigame with a hard deadline. Survive it and it's logged as a win. Fail it, and that's logged too — right alongside every raid you've walked away from.

// under the hood

System specifications

Layer Detail
Engine raylib, fixed 1920×1080 reference canvas with automatic scale + letterbox for any monitor.
Networking Lightweight UDP client/server protocol (VNET) — chat, whispers, pings, and raid traffic between real connected players.
Rendering Fully custom immediate-mode UI. No widget library, no retained scene graph — every frame redraws terminal, browser, CLI, and overlays.
State A single global Player struct carries connection state, trace level, flags, vcoin, and raid state.
Language Modern C++17, organized by feature (raid/, connection/) rather than by engine layer.

Controls, once you're connected:

Tab Toggle the CLI terminal
Enter Submit the current CLI command
Scroll Scroll the terminal or browser pane, depending on focus
F1 / F2 FPS counter / debug overlay
F11 Toggle fullscreen
